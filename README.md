# Редактор для проведения собеседований

## Устройство

Статический редактор на основе monaco-code-editor и @babel/standalone

## Поддерживает

-   React
-   ReactDOM
-   Styled-components
-   Typescript

## Назначение

Проведение технических интервью с шарингом экрана, для проверки знаний разработки Frontend

## Моковые fetch запросы

У редактора есть возможность обрабатывать моковые fetch запросы, для этого можно описать массив rest урлов в api фрейме (если его нет, то нужно включить через toggle api).

Каждая ручка должна быть описана объектом который содержит три поля:

-   url - строка относительного пути, по которому вы будете делать запрос (обязательно);
-   data - данные которые должны возвращаться из ручки (обязательно);
-   delay - задержка ответа в мс (не обязательно).

Пример запроса:

```javascript
fetch('/profile')
    .then((res) => res.json())
    .then((data) => console.log(data))
    .catch((err) => console.error(err));
```

Пример описания ручки:

```json
[
    {
        "url": "/profile",
        "data": {
            "fullname": "Ivan Ivanov",
            "position": "Developer"
        },
        "delay": "3000"
    }
]
```
